# Policy Source: Security

This is a routing marker, not a replacement for the policy. The canonical
policy is the complete repository-root file `Security.md`.

When `Security` is active, read the entire canonical file from beginning to
end. Apply every applicable control and record exclusions with reasons. Never
call a partial scan a complete security review.

Coverage includes: application and priorities; the universal security
profile, trust and authority, schemas and DTOs, injection and parsing,
resource limits, authentication and sessions, recovery, authorization,
cryptography, memory, and privacy; backend/API/database/finance controls;
web and embedded-web controls; native application controls; Windows,
Android, macOS, and cross-platform rules; updates, supply chain, audit,
disaster recovery, mixed versions, engineering, and performance; and testing,
standards, evidence, exceptions, and delivery requirements.

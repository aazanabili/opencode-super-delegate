# GitHub Actions

Inspect workflow triggers, permissions, environments, dependency actions,
secrets references, concurrency, artifacts, and required status checks. Validate
YAML and repository conventions before proposing changes. Workflow edits are
code changes and require normal review; dispatching or rerunning a workflow is
an external side effect requiring approval. Never expose secret values or copy
unnecessary private logs. Distinguish queued, running, cancelled, failed, and
successful runs and return run IDs/URLs with evidence.

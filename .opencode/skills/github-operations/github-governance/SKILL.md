# GitHub Governance

Inspect existing CODEOWNERS, PR/Issue templates, workflow permissions, rulesets,
required checks, Dependabot, CodeQL, and secret-scanning configuration before
changing anything. Prefer repository files and documented configuration over
opaque administrative mutations. Administrative settings require a separate
approval, an impact summary, and post-change verification. Never weaken branch
protection, required reviews, or secret controls as a workaround for failures.

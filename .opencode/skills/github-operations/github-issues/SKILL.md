# GitHub Issues

Search for duplicates before creating an Issue. Use the repository's existing
templates, labels, milestones, and Projects. Include reproducible context,
acceptance criteria, scope, and links to related PRs. Issue creation, closing,
label changes, and project mutations are external operations and require the
applicable approval. Return issue numbers and URLs.
